# Вебсайт «Допомога біженцям»

Індивідуальне завдання №2 — «Створення вебсайту».

## Структура сайту

- `index.html` — Головна сторінка (рівень 1, найвідвідуваніша)
- `about.html` — Про проєкт (історія, місія, цінності)
- `help.html` — Як допомогти (способи підтримки, таблиця потреб)
- `contacts.html` — Контакти (пошта, телефон, форма зворотнього зв’язку)
- `style.css` — стилі (колірна гамма, типографіка, адаптивність)
- `README.md` — цей файл


## Виконані вимоги методички

1. Тема проєкту — «Допомога біженцям» (обґрунтована, актуальна).
2. Назва сайту — «Допомога біженцям».
3. Struktura — не більше трьох рівнів вкладеності.
4. Рівень 1 — Головна сторінка з основним розділом тем.
5. Теми поділені між сторінками (Про проєкт, Як допомогти, Контакти).
6. Колірна гамма — 2–3 гармонійних кольори (помаранчевий, зелений, світлий бежевий).
7. Типографіка — основний sans-serif шрифт та альтернативний serif для акцентів.
8. Адаптивність — сайт коректно відображається на смартфоні, планшеті та ПК (мобільне меню, гнучкі сітки).

## Зображення

У коді посилання на зображення вказують на файли в кореневій папці проєкту (наприклад, `Наша місія.jpg`). 
Ви можете додати свої файли у цю папку або замінити посилання на реальні URL.

## Як відкрити локально

Відкрийте папку `вебсайт` і двічі клікніть по `index.html`.

## Як опублікувати в інтернеті

Щоб інші люди могли заходити на сайт за посиланням, розмістіть його на безкоштовному хостингу:

### Netlify Drop (найшвидший спосіб)
1. Збережіть усі файли сайту в одну папку.
2. Зайдіть на [https://app.netlify.com/drop](https://app.netlify.com/drop)
3. Перетягніть папку мишкою на сторінці.
4. Отримайте посилання типу `https://звічкове-имя.netlify.app` і надішліть його людям.

### GitHub Pages
1. Зареєструйтеся на [https://github.com](https://github.com).
2. Створіть репозиторій (наприклад, `dopomoga-bizhencom`).
3. Завантажте туди файли сайту.
4. У репозиторії зайдіть у **Settings → Pages**, оберіть гілку `main` і натисніть **Save**.
5. Отримаєте посилання типу `https://ваш-логін.github.io/dopomoga-bizhencom/`.

Після публікації скопіюйте URL та вставте у звіт за завданням.
